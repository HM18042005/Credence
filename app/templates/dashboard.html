🔌 API Endpoints

POST /api/v1/msme

Create a new MSME entity

POST /api/v1/ingest/bank-transactions

Ingest bank transactions in AA format

POST /api/v1/ingest/gst-cashflows

Ingest GST cashflows in AA format

POST /api/v1/assess/loan-eligibility

Assess loan eligibility and calculate credit limits

GET /api/v1/assessments/{msme_id}

Get credit assessment history for an MSME
